# СтудЕда

Светлая мобильная версия приложения в стиле макета пользователя.

## Функции
- рацион и КБЖУ за день;
- история питания;
- напоминания;
- продуктовая корзина и бюджетные рецепты;
- Free / Premium;
- Premium: персональные цели, 7-дневная аналитика, умный подбор блюд.

## Render
Runtime: Python
Build Command: `echo "No build required"`
Start Command: `python app.py`

Если проект лежит внутри папки `student_food_web_render_ready`,
укажите эту папку в Render → Root Directory.

Никакой `pip install` не нужен.
