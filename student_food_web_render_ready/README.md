# Student Fuel — Free + Premium

Локальный сайт на Python. Никаких `pip install` не требуется.

## Запуск
1. Полностью распакуйте ZIP.
2. Дважды нажмите `start_windows.bat`.
3. Не закрывайте чёрное окно.
4. Браузер откроется автоматически на свободном локальном порту.

## Режимы

### Free
Полностью доступны:
- учёт приёмов пищи и КБЖУ;
- история по дням;
- напоминания;
- каталог продуктов;
- рецепты и перенос рецептов в рацион.

### Premium
Дополнительно:
- собственные дневные цели КБЖУ;
- аналитика питания за последние 7 дней;
- подбор нескольких рецептов с учётом оставшихся калорий и белка.

Переключатель FREE / PREMIUM находится справа в верхней панели.
Это демонстрационный переключатель: оплаты нет.

Все записи истории и напоминаний сохраняются в SQLite.
Premium-режим и пользовательские цели сохраняются в браузере через localStorage.
