# СтудЕда — приложение для проекта о питании студента

Это локальное web-приложение **на чистом Python**. Никакие библиотеки через pip устанавливать не нужно.

## Что в нём есть

- **Умный рацион**: учитывает бюджет, цель по калориям и белку, максимум времени на готовку и учебное расписание.
- **Режим сессии**: одним нажатием ограничивает готовку до 12 минут.
- **Дневник питания без рутины**: знакомые блюда добавляются в один клик, ручной ввод оставлен как запасной вариант.
- **Продуктовая корзина**: переводит граммы из рациона в реальные упаковки и показывает реальную сумму на кассе.
- **Запасы дома**: уже купленные продукты вычитаются из списка покупок; можно указать срок годности.
- **База бюджетных блюд**: цена, время, КБЖУ, теги «с собой», «быстро», «бюджетно».
- **Расписание пар**: если обеденное время занято, генератор выбирает переносимые блюда.
- **Напоминания**: при разрешении браузера показывают уведомления, пока приложение открыто.
- **Аналитика недели**: показывает общую картину без перегрузки цифрами.
- **Стандарт / Премиум**: стандартная версия полноценная, премиум добавляет план на 3 дня и больше автоматизации.

## Самый простой запуск на Windows

1. Распакуйте ZIP в обычную папку, например `C:\StudentFood`.
2. Дважды нажмите **start_windows.bat**.
3. Приложение само откроет браузер по адресу `http://127.0.0.1:5000`.

Если Windows пишет, что команда `python` не найдена, установите Python 3 и во время установки отметьте **Add Python to PATH**.

## Запуск вручную

```bash
python app.py
```

На macOS/Linux:

```bash
python3 app.py
```

## Где хранятся данные

Рядом с приложением автоматически создаётся `student_food.db`. Там сохраняются дневник, расписание, настройки, напоминания, запасы и планы.

Чтобы полностью сбросить демо-данные, закройте приложение, удалите `student_food.db` и запустите снова.

## Важно

Калории, БЖУ и цены в прототипе ориентировочные. Приложение создано для учебного проекта, а не как медицинский сервис.


## Вертикальный интерфейс

В этой версии интерфейс переработан под вертикальный формат: приложение выглядит как мобильный помощник, контент идёт одной колонкой, основные разделы доступны через нижнюю навигацию, а полное меню открывается сверху. На широком экране приложение остаётся в аккуратной портретной рамке, поэтому его удобно показывать как прототип мобильного сервиса.
